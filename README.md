# 🎮 The Elder Scrolls II: Daggerfall — 3DS Port

Un proyecto experimental cuyo objetivo es intentar adaptar **The Elder Scrolls II: Daggerfall** para Nintendo 3DS mediante un motor propio desarrollado en C++.

La idea no es ejecutar directamente el juego original, sino desarrollar una nueva implementación capaz de interpretar sus datos y sistemas, adaptándolos a las capacidades y controles de la Nintendo 3DS.

---

## 🧠 Concepto

El proyecto busca recrear la experiencia de Daggerfall desde un motor diseñado específicamente para 3DS, manteniendo los datos y sistemas originales del juego siempre que sea posible.

La pantalla superior estará enfocada en la exploración y el gameplay, mientras que la pantalla táctil podrá utilizarse para elementos como:

- Inventario y equipamiento.
- Estadísticas del personaje.
- Información de habilidades.
- Mapas.
- Mapas tridimensionales de las dungeons, con interacción táctil.

Los archivos originales del juego se utilizarían como datos externos, permitiendo que el proyecto distribuya únicamente el software necesario para ejecutar la adaptación.

---

## 🛠️ Tecnologías

- C++
- Nintendo 3DS / Homebrew
- devkitPro / devkitARM
- libctru
- CMake / Make
- OpenTESArena como referencia técnica

---

## 🚧 Estado

**Concepto / Investigación**

El proyecto se encuentra actualmente vacío. La implementación del motor, la interpretación de los datos de Daggerfall y la viabilidad del port todavía están por desarrollarse.

El objetivo inicial es determinar hasta qué punto es posible adaptar Daggerfall a Nintendo 3DS, especialmente teniendo en cuenta las limitaciones del hardware y la compatibilidad con un Old 3DS.
